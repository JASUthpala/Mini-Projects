# Mini Projects:

## 1. Lecture-AI

A simple local application that converts lecture audio or PDF files into short summaries and useful questions. It runs completely offline after the first setup.

How to run?

1. Start the backend:
   cd "d:\Mini-Projects\Lecture-AI\backend"
   C:\Python313\python.exe app.py

2. Start the frontend:
   cd "d:\Mini-Projects\Lecture-AI\frontend"
   C:\Python313\python.exe -m http.server 8000

3. Open:
   http://127.0.0.1:8000
